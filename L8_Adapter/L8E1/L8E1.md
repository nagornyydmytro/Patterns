# L8E1 (USB charger)

У цій задачі реалізовано шаблон Адаптер для заряджання телефона з роз’ємом USB Type-C через зарядний пристрій з роз’ємом micro-USB.

Було реалізовано два варіанти адаптера:
- `AdapterMicroUsbToTypeC` — через композицію
- `AdapterMicroUsbToTypeCInheritance` — через наслідування

У варіанті через композицію адаптер зберігає всередині об’єкт `MicroUsbCharger` і на його основі повертає потужність, яку очікує інтерфейс `TypeCCharger`.

У варіанті через наслідування адаптер успадковується від `Charger` і одночасно реалізує інтерфейс `TypeCCharger`.

Реалізація через композицію є більш гнучкою, тому що адаптер не прив’язаний жорстко до одного конкретного класу. Такий варіант простіше розширювати.

Реалізація через наслідування коротша, але менш гнучка, бо адаптер уже залежить від конкретного базового класу.

Тому для цієї задачі кращим варіантом можна вважати адаптер через композицію.
